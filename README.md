# ODEKAKE NOTE ♨

家族で行ったサウナ(など)を記録するスマホ向けアプリ(PWA)。

- 施設名・日付・メンバー・★評価・感想・写真を記録
- データは各自のスマホ内に保存(サーバー不要)
- 「バックアップ」から書き出し/読み込みで家族とデータを受け渡し
- ホーム画面に追加すると、アプリのように使えます

## 家族で自動共有する設定(Firebase)

1. https://console.firebase.google.com でプロジェクトを作る(Googleアナリティクスはオフでよい)
2. 「構築」→「Firestore Database」→「データベースを作成」。ロケーションは `asia-northeast1`(東京)、モードは本番モード
3. 「ルール」タブに `firestore.rules` の中身を貼って公開
4. プロジェクトの設定 → マイアプリ → ウェブ(`</>`)を追加し、表示される `firebaseConfig` を `firebase-config.js` に貼る
5. 公開後、バックアップ画面の「家族を招待する」で出るリンクを家族に送る

`firebase-config.js` が空のあいだは、各自のスマホ内だけに保存する動きになります。
招待リンクを知っている人は誰でも記録を見られて書き込めるため、家族以外には送らないでください。
